# User support

Use GitHub Issues for non-sensitive defects and compatibility problems. Search existing issues
first and use a synthetic example whenever possible.

## Safe information to include

- application version;
- Windows edition, display version, build, and native architecture;
- WebView2 version shown in Settings;
- the fixed warning or failure code;
- exact steps using non-private sample content;
- the exported **Safe diagnostic report** after reviewing it locally.

## Never post publicly

Do not upload question or answer images, backups, databases, recovery keys, tokens, email
addresses, student names, school/class identifiers, filenames, or private local paths. Security
problems must use the private vulnerability-reporting flow in `SECURITY.md`.

## Known distribution behavior

- Free-channel installers are intentionally unsigned and can show Unknown publisher or
  Microsoft Defender SmartScreen warnings.
- Core use is offline-first. Cloud controls are unavailable when the build has no configured
  backend.
- Smart question-region output is a reviewable suggestion. Users must inspect boundaries before
  placing derived material into the library.
- Uninstalling the application is designed to preserve the encrypted library. Create a verified
  backup before upgrades, storage moves, repair attempts, or uninstall/reinstall recovery.
