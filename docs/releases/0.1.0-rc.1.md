## Known limitations

- Local question splitting is review-required. The 60-image development and 300-image blind evidence gates are not complete, so automatic accuracy is not a release claim.
- Centralized crash-rate, update-adoption, and sync-health monitoring are not part of this candidate; support relies on privacy-safe local diagnostics and explicit user export.
- Test runs on this development machine have emitted SQLCipher `VirtualLock` Windows error 1453 warnings without test failures. Resource-pressure behavior remains part of manual acceptance.
- Legal terms, privacy publication, sales support policy, refund terms, and any cloud-account deletion obligations require product-owner approval before public paid promotion.
