# Windows 支持与兼容策略

本策略用于正式发布版本，不把“能启动”误称为“受支持”。Mistake Trainer Next
采用 x64、当前用户安装和本机加密资料库；安装器携带 Microsoft Evergreen
WebView2 离线安装程序，因此首次安装不依赖外网。

## 支持矩阵

| 状态 | Windows 环境 | 承诺 |
| --- | --- | --- |
| 正式支持 | Microsoft 仍提供安全更新的 Windows 11 x64 | 完整安装、升级、备份恢复、采集、训练与智能切图支持 |
| 延伸兼容 | Windows 10 22H2 x64 且已加入 ESU；仍在生命周期内的 Windows 10 LTSC x64 | 保持核心功能兼容；与系统生命周期或显卡驱动相关的问题可能要求升级 Windows |
| 延伸兼容 | Microsoft 仍提供安全更新的 Windows 11 ARM64，安装 ARM64 原生包 | 基础题库与采集使用原生构建；智能识图性能仍需按 ARM64 设备单独验收 |
| 尽力而为 | Windows 11 ARM64 上运行旧 x64 包的系统仿真 | 仅用于迁移；应改装 ARM64 原生包 |
| 不支持 | Windows 7、Windows 8/8.1、32 位 Windows、Windows Server、Wine、精简或修改版 Windows | 不发布兼容承诺，不接受以生产资料验证 |

最低技术基线为 Windows 10 1809（内部版本 17763）x64；ARM64 原生包要求 Windows
11（内部版本 22000 或更高）。普通 Windows 10
Home/Pro 已在 2025-10-14 结束常规支持；继续使用时必须由用户或组织确保仍能获得
Microsoft 安全更新。Windows 7/8 即使能运行某些旧 WebView2 组合，也不进入正式版
支持范围。

## 安装与运行时

- 分别发布 x64 与 ARM64 NSIS `-setup.exe`，文件名和下载页面必须清楚标注架构，禁止
  用“通用安装包”掩盖实际架构。默认安装到当前用户的 `%LOCALAPPDATA%`，不因应用本身
  要求管理员权限。
- 安装器包含 Evergreen WebView2 离线安装程序。没有 WebView2 的离线电脑也能完成
  先决条件安装；运行后仍使用 Microsoft 维护的共享 Evergreen Runtime，以获得安全
  更新。
- 安装器禁止用旧版本覆盖新版本。跨版本回退必须先做加密备份并显式卸载。
- 简体中文与英文安装文本打入同一个安装器，默认跟随 Windows 显示语言。
- 正式发布的应用程序与安装器必须使用同一个受信任发布者身份做 Authenticode
  SHA-256 签名和 RFC 3161 时间戳。CI 产生的未签名安装包只能用于测试。

## 硬件与降级

- 基础题库、训练、备份和手工整理不要求 AVX2 或独立显卡。
- 智能切图使用本地视觉分析；可选 OCR 根据处理器、内存、磁盘和 AVX2 能力决定
  是否开放模型，不满足条件时回退到模板与手工整理。
- 建议至少 8 GB 内存、4 个逻辑处理器、2 GB 可用磁盘空间。低于建议值不会损坏
  资料，但批量图片处理会变慢。
- 125%、150% 和 200% 显示缩放属于发布验收范围。

## 数据、路径与权限

- 默认资料库保存在 Windows 应用数据目录并使用 SQLCipher 与加密资源仓库。
- 支持中文用户名、空格和 Unicode 路径。自定义资料库位置必须可写且能保持稳定挂载；
  网络共享、同步盘按需文件和会自动断开的移动盘不建议作为唯一资料库。
- 升级和卸载不得删除本机加密资料库。卸载前仍建议在设置中创建完整加密备份。
- 同一 Windows 用户会话只允许一个应用实例操作资料库；再次启动应聚焦已有窗口。

## 用户支持证据

处理兼容问题时先让用户在“设置 → 安全诊断”导出隐私报告。报告只包含应用版本、
Windows 构建、CPU 架构、WebView2 版本、资料库聚合计数与固定警告码，不包含题目、
答案、姓名、标签、文件名、路径、账户 ID、令牌或密钥。若上一次运行发生 Rust panic
或 Tauri 启动失败，诊断报告还会包含固定的失败类型、应用版本与时间；不会复制 panic
文本、堆栈、内部错误或本机路径。损坏、未知或超过 4 KiB 的启动记录会被忽略，不影响
用户继续导出诊断报告。

若程序在窗口出现前失败，发布版会写入不含内部错误详情的启动失败记录，并显示原生
Windows 提示。支持人员应同时收集：

1. 安装包版本和签名发布者；
2. Windows 版本、内部版本与是否有 ESU/LTSC；
3. 安装/升级/首次启动中的具体阶段；
4. 安全诊断报告或启动失败记录；
5. 是否使用安全软件、代理、企业策略或精简系统。

## 发布验收

每个候选版本至少验证：

- Windows 11 23H2、24H2、25H2 x64；
- Windows 11 当前受支持版本 ARM64，使用 ARM64 原生安装包；
- Windows 10 22H2 ESU x64、Windows 10 LTSC 2019 x64；
- 标准用户、中文用户名、Unicode 自定义路径、离线安装；
- 从上一签名版本升级、阻止降级、卸载后资料保留；
- 重复启动聚焦已有窗口；
- NSIS 静默安装、自检与卸载；
- 安装器和主程序 Authenticode 签名、时间戳与 SHA-256 校验值。
