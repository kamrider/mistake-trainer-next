# Windows 资料库生命周期验收

每个 x64 与 ARM64 发布候选都要在临时 Windows 账户中验证以下状态：全新安装、正常
重装、卸载后重装、仅数据库缺失、仅资源目录残留、完整或部分 Windows 凭据残留、
外置位置断开，以及迁移、备份恢复、重新开始在每个日志边界被中断。

验收不变量：

- 只有文件、指针、挂起日志和五项本机凭据全部不存在时，才允许建立首个空库。
- 任何旧资料证据不完整时，应用都显示固定恢复原因，且不创建目录、不打开替代库。
- 重试通过进程重启重新盘点；同一进程内的冻结访问门不会假装状态已经改变。
- 重连在写指针前完成只读 SQLCipher、账户、完整性和资源相对路径验证。
- 缺失库从备份恢复失败时，唯一候选仍在暂存目录；不得产生空库。
- 重新开始需要输入 `永久放弃原资料库`，中断后由 `library-reset-pending.json` 收敛。
- 安装器冒烟仅在 Windows Sandbox 或显式临时 CI runner 中执行，父进程中断后无孤儿 GUI。

发布记录只附固定失败码和聚合数量，不附路径、用户名、账户 ID、凭据、题目或图片。
