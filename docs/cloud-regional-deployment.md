# 云端同步与网络区域说明

Mistake Trainer Next 的数据路径始终是“本地优先”：训练、采集、原图和待同步 outbox 先写入 Windows 本地加密库。云端连接失败不会阻止继续使用，也不会删除本地数据。

## 中国大陆使用建议

- v1 默认选择“仅本地”。它不需要外网，适合单机使用和局域网手机采集。
- Supabase 适合海外或开发环境；在中国大陆可能遇到连接超时、验证邮件延迟或跨境网络抖动。它不是本地采集链路的依赖。
- 如果已经配置 Supabase，网络暂时不可用时界面会显示“离线模式”，待同步变更继续留在本地 outbox，网络恢复后再手动同步。
- “腾讯云（国内预留）”目前只保留产品边界和设置项，适配器尚未启用，不会因为选择该项而上传数据。

正式支持国内云同步前，需要单独完成兼容的认证、对象存储、RLS/权限、断点续传和双设备契约测试；不能仅替换一个 URL 就宣称可用。
